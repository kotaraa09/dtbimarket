# 06-log

One file per month: `YYYY-MM.md`. Append one line per working session. Newest at the bottom.

```
2026-09-03  Event table + emitter. First events landing from product create.
2026-09-04  Assignment service. Server-side only, unique constraint added.
2026-09-05  Tried Redis for assignment cache — dropped, Postgres is fast enough here.
```

Short entries. This exists so that in month five you can reconstruct why something is the way it is, and so the retrospectives and the thesis methodology chapter have something real to draw on.
