# 03-research

This folder is the thesis. Treat it as the most important directory in the repository.

**The rule that matters:** an experiment is designed here, in writing, *before* any code is written for it. Copy `experiments/TEMPLATE.md`, fill it in, then build.

Writing the analysis plan before the data exists is not bureaucracy. It is what stops you from searching a finished dataset for whichever comparison happens to look significant, which is the fastest way to produce a result that does not survive questioning.

- `hypotheses.md` — what we predict and why
- `analysis-plan.md` — how every metric is computed, written before data exists
- `experiments/` — one file per experiment
- `findings/` — results, **including the ones that did not work**

A negative result is a finding. Record it with the same care as a positive one.
